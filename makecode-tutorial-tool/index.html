Makecode Tutorial Tool

Thu, Nov 28, 2024 · Rob

I’m a fan of Microsoft MakeCode going back to when its main use was for programming the micro:bit (which I’m also a huge fan of, as you can see from some of my micro:bit posts). One of the things I really liked was Microsoft’s publishing of the MakeCode Tutorial Tool which lets you create your own step-by-step tutorials, which you can then access via a share link, so you don’t even need to host anything yourself.

Tutorial tool#

I’ve always thought the Tutorial Tool was pretty underrated, with little fanfare given how useful it is. I think I learned about it following Peli de Halleux over on the dead bird site (which I won’t link to but here’s a LinkedIn profile).

In a nutshell the tutorial tool lets you create a tutorial for students to follow with scaffolding code, hints, and images, using markdown. The tool is integrated with a live MakeCode environment (with a choice of platforms, like micro:bit and Minecraft: Education Edition) so you can build a step of the tutorial, use the created JS code to embed in your tutorial, and also preview the results. Once you’re done, create a share link and stick it into your LMS of choice with your other teaching resources.

Once students are done with a tutorial they can save it to their project list as a base for their own code or as a reference, or share it for collaboration or feedback.

Platforms#

My own main uses of MakeCode have been for micro:bit and Arcade, both of which work really well with the tutorial tool as you get the simulator built into the interface, and so get a nice tight feedback loop for the student about what works as expected and what doesn’t.

The tutorial tool also supports other platforms like:

  • Circuit Playground Express
  • Minecraft Education Edition
    The Minecraft: EE web editor isn’t as useful as the others as it doesn’t have a simulator. In my experience having immediate feedback is particularly important in Minecraft as it relies so much on spatial awareness, and my students (and myself) frequently had trouble with the coordinate system.
  • Maker
    This appears to be a pretty big collection of microcontrollers from Adafruit’s products, to Arduino, to Raspberry Pi Pico. The simulator is pretty barebones (which you would expect given the range of supported hardware), so it would be more useful just as a visual editor.

MakeCode has been adopted for a number of other platforms, but these don’t seem to be supported by the tutorial tool.

Skill maps#

Saving progress#

One of the really nice things (that didn’t exist back when I used the Tutorial Tool with my classes) is account progress saving (MS, Google, Clever identity providers). Even when progressing through third party skill maps or tutorials (i.e. yours) using an external GitHub repo, it will still save progress.
